## Current implementation

- Native Gemini calls and observations persist independently of conversation summaries. A browser step pauses the turn; acknowledgment resumes its exact native continuation.
- Owner/turn/controller-tab checks, execution leases, stop fencing, replay receipts, per-target tab observations and partial/popup recovery are additive.
- Website functions invoke existing owner-scoped customer services for collections, account context, compatibility, group terms, own orders and preparation of customer workflows. No seller tools or financial-approval function is exposed.
- Actual registered links and opted-in component controls are observed at runtime. No executable JavaScript, selectors or coordinates come from the model.
- Existing natural conversation, catalog RAG, history, styling and microphone transcript input are preserved.

## Regression migration

Historical executor tests called functions no longer exposed by the approved natural Gemini/catalog interface, expected the old native-message cache to be the conversation archive, and required a canned variant-choice reply without a model generation. Those assertions now test current catalog observations, Gemini-authored clarifications, actual website functions and the durable execution journal. Legacy service permission/stock/checkout/group tests remain. Integration fixtures explicitly configure the large model context used by this agent rather than assuming an 8 KiB local-model budget; undersized contexts still fail before effects and are covered by the memory/context tests.

Implementation checkpoints are `d7da111`, `221339c`, `1e2dba9`, `9656293`, `0f5c63d`, and `3507760`. No hosted rollout has been attempted.

## Measured live behavior and remaining scope

The earlier three live tasks took 29.6 s, 22.5 s, and 34.5 s. A fresh run after the customer/concurrency changes passed all three tasks in 41.4 s, 47.3 s, and 66.6 s, with 2, 2, and 4 native calls respectively. Those are whole tasks, including model/tool/browser round trips, measured while other local verification was running. They are acceptance samples, not a latency benchmark or a subsecond-answer claim. Billing and provider settings were unchanged. The first live attempt exposed an ambiguous “show cart” interpretation; the explicit `show_collection` capability fixed the composed operation on recheck.

A screenshot review then found raw retrieval candidates displayed as recommendation cards. Catalog reads are now marked internal; cards derive from observed selected product actions. Native Gemini prose is unchanged. The active execution journal still retains all read results.

Customer controls, category sorting/pagination, direct quotes, file selection/submission, independent group commitments, checkout review, owned cancellation/return and session changes are implemented. New native execution archives retain completed/canceled tasks beyond the bounded UI cache. Basket revisions and control/page preconditions protect newer manual edits; a failed dependent batch requires replanning before more writes.

Browser qualification caught and repaired a quote dialog that tried to resolve a newly opened product through a smaller legacy cache, tab opening order that depended on registration order, and homepage readiness that incorrectly required an `h1`. The quote now retains the actual selected product; tab metadata retains requested opening order; home/shop readiness uses an explicit component marker.

**The whole marketplace and hosted A0–A9 release is not declared production-ready.** The remaining catalog/media gate is documented in the triage report. The conversational control implementation does not waive it. Physical microphone/accent/noise quality, a full browser/device/accessibility/load matrix, every possible Gemini utterance and external PayPal approval are not certified by the local samples. Financial approval, credentials and file picking retain their existing customer/browser interactions. Broader remedy/appeal/shipping behavior is covered by existing customer service contracts and opted-in forms; it is not represented as a separately sampled live-Gemini browser journey.

Reproduction: `npx playwright test --config=playwright.chat-memory.config.ts`; optional local speech assets: `npx playwright test --config=playwright.website-voice.config.ts`. Fixture model commands exist only in the isolated test server, never in production conversation routing. The configured live model remains `gemini-3.5-flash-lite` with local BGE retrieval; no provider/model switch or billing change was made.
